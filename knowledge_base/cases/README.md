# 案例

## 文件用途

存放结构化真实案例及脱敏兼容样本。`verified/` 收录可由最高人民法院官方页面核验的指导性案例；根目录五类文件为流程兼容样本，不对应特定裁判文书，不得作为裁判依据引用。

## 数据格式

真实案例使用 UTF-8 JSON，字段以 `knowledge_base/schema/case_schema.json` 为准，包括案名、案号、法院、年份、案由、事实、争点、两审结果、裁判理由、法律依据、律师策略、来源等级和原始来源。录入前必须完成来源核验、个人信息脱敏和使用合规审查。

## 后续 RAG 接入方式

`legal_assistant/case_rag.py` 当前提供确定性关键词和案由召回。后续录入真实案例时，应以争议焦点、裁判理由和裁判要旨分别切分，并标记法院层级、案由、日期、地域和引用法条；召回应优先返回原始公开来源。
