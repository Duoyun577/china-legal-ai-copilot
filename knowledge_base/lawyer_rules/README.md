# 律师执业规则

## 文件用途

存放律师执业、律师事务所管理、职业道德、利益冲突、保密及行业惩戒相关规范。当前目录仅保留说明，不录入规范正文。

## 数据格式

建议使用 UTF-8 JSON 或 Markdown 文件，字段包括 `document_id`、`title`、`issuer`、`document_type`、`effective_date`、`status`、`scope`、`articles`、`source_url`。涉及地方律协规则时应记录适用地域和版本。

## 后续 RAG 接入方式

按规则条款、合规义务与禁止性要求进行切分，附带适用主体、地域、效力状态及生效日期。检索时先匹配执业场景与地域，再用向量检索定位具体义务，并展示可追溯来源。
